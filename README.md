# 🛠️ Windows Repair Toolkit

> A collection of Windows repair scripts and utilities for diagnosing, repairing, and maintaining common Windows system issues.

Windows Repair Toolkit is a lightweight collection of `.BAT` scripts and `.EXE` utilities designed to help troubleshoot and repair common Windows problems.

The toolkit focuses on practical system maintenance, network repairs, Windows component recovery, cache cleanup, and other common fixes.

---

## ✨ Features

* 🛠️ Windows system repair tools
* 🌐 Network troubleshooting and reset
* 🧹 Temporary file and cache cleanup
* 🔧 Windows component repair
* 📦 BAT automation scripts
* ⚡ Standalone EXE utilities
* 🖥️ Simple command-line interface
* 🔍 Diagnostic utilities
* 🚀 Quick fixes for common Windows problems

## 🔧 Available Tools

### BAT Scripts

The BAT scripts automate common Windows maintenance and repair operations.

Examples:

| Tool                | Purpose                                       |
| ------------------- | --------------------------------------------- |
| `network_fix.bat`   | Repairs common network configuration problems |
| `system_repair.bat` | Runs Windows system repair operations         |
| `cleanup.bat`       | Removes unnecessary temporary files           |
| `dns_fix.bat`       | Resets DNS-related configuration              |
| `cache_clear.bat`   | Clears selected Windows caches                |

> The exact scripts available in the repository may change over time.

### EXE Utilities

The repository also contains standalone executable utilities for specific repair or diagnostic tasks.

Each executable should be used only for its intended purpose.

## 🚀 Usage

### 1. Download

Clone the repository:

```bash
git clone https://github.com/vidmo404/Windows-Repair-Toolkit.git
cd Windows-Repair-Toolkit
```

Or download the repository as a ZIP from GitHub.

### 2. Run a Tool

On Windows, double-click the desired `.bat` or `.exe` file.

Some tools may require **Administrator privileges**.

If a script requires administrator permissions, right-click it and select:

```text
Run as administrator
```

### 3. Follow the Instructions

Some tools may restart services, reset network configuration, modify system settings, or repair Windows components.

Read the console output before closing the window.

## 💡 Why?

Windows problems can sometimes be fixed with a few commands, but remembering every command can be annoying.

This project collects useful repair operations into simple, reusable tools.

Instead of manually entering multiple commands, you can run the appropriate repair utility and follow the instructions.
